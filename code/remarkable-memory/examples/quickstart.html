01Connect the tablet

Run once. The skill preflights the connection and walks you through whichever transport your tablet supports.

Claude Code
/remarkable-memory setup

Plug in over USB first. The skill checks the link, the port, and the MCP server separately, so a failure tells you which of the three is wrong instead of just "no documents".

If the USB web interface won't come up. A healthy ping with Connection refused on port 80 means the link is fine and the tablet's web server simply isn't listening. Toggle Settings → Storage → USB web interface, and keep the screen awake — it stops serving when the tablet sleeps. If it still refuses, switch to SSH: it ignores the lock screen entirely and is the more reliable path.
Never enable developer mode to "fix" a connection. It factory resets the device. If nc -z 10.11.99.1 22 reports the port open, SSH is already available and developer mode is not needed.

02First sync — start narrow

Don't pull twenty notebooks blind. Take one, check how well your handwriting reads, then widen.

Claude Code
/remarkable-memory sync --notebook "Daily Log" --since 30d

You get a scoped plan to confirm before anything is extracted. Re-running is safe — pages are keyed by doc_id:page:modified, so unchanged pages are skipped without even pulling the render.

Plain English works too, and is often faster than remembering flags: /remarkable-memory sync then "last 30 days of daily logs".

03The morning ritual

The highest-value habit: sync what you wrote since yesterday, then have Claude reflect it back before you plan the day.

Claude Code
/remarkable-memory sync since yesterday for my today plan and reflection on yesterday

Sync and intent in one line. The skill pulls only new pages, then answers from them — so the reflection is grounded in what you actually wrote, with a page citation on every claim.

Why this beats reading the pages yourself: the answer cites notebook · page for every point, so you can always jump back to the original ink.

04Catch up after a gap

--yes skips the confirmation gate. Use it once you trust the scope — handy for a repeat weekly pull.

05Ask the memory

Anything that isn't a known subcommand is treated as a question against your notes.

Claude Code
/remarkable-memory what did I write about the agent protocol spec
Claude Code
/remarkable-memory summarize my product design thinking from the past 20 days
Claude Code
/remarkable-memory which open questions did I write down but never resolve

That last one is the sort of question a pile of paper can't answer. Answers are confidence-aware — if a claim rests on a page read at 0.6, it says so.

07Hand a topic to another agent

The memory is plain Markdown, which makes it a clean hand-off format between sessions, agents, or people.

Claude Code
/remarkable-memory the pages about my essay on memory and craft —
export them to ~/Desktop/essay-notes/ so another agent can pick them up

Scattered thinking across weeks of pages becomes one folder a fresh session can read cold. No context transfer, no re-explaining.

Because it's a git repo, you can also just point another tool at it: ~/remarkable-memory/notes/ is greppable Markdown with YAML frontmatter.

09Teach it your handwriting

This is the step most people skip, and it's the one that compounds. Every correction is written to a guide the extractor reads on every future sync.

Claude Code
/remarkable-memory review

Starts with the lowest-confidence pages. If more than a handful are flagged it offers a bulk path first — you skim them in the HTML view and accept the ones that read fine, then walk only the genuinely ambiguous pages one at a time.

Claude Code
/remarkable-memory review --min-confidence 0.85

Widens the net — review anything read below 85% certainty, not just the flagged ones.

What "learning" actually means here. No hidden model, no fine-tune. Corrections land in corrections.md; recurring patterns get promoted into extraction-guide.md — a plain file you can open and edit yourself. Seed it directly if you like: "in my notes, 'EOD' means end of day, and boxed text is always a decision".
An unreviewed memory stops improving. If average confidence is sitting near your threshold and extraction-guide.md is still empty, the reader has learned nothing about your hand yet. One review pass is the difference between a memory that stays at 0.75 and one that climbs.
