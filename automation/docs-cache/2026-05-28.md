### Key facts relevant to skill authoring

**Frontmatter requirements:**
- `name`: ≤64 chars, lowercase + hyphens only, no XML tags, cannot contain "anthropic" or "claude"
- `description`: non-empty, ≤1024 chars, no XML tags. Must cover both what the skill does AND when to use it.

**Three loading levels:**
- Level 1 (always): YAML frontmatter — loaded at startup, ~100 tokens per skill
- Level 2 (on trigger): SKILL.md body — loaded when skill activates, <5k tokens
- Level 3 (as needed): bundled files (scripts, resources) — loaded on demand, no practical limit

**Surface availability:**
- **claude.ai**: individual user only (not org-wide). Upload as zip. Pro/Max/Team/Enterprise with code execution enabled. Network access varies by user/admin setting.
- **Claude API**: workspace-wide. Upload via `/v1/skills`. Requires beta headers: `code-execution-2025-08-25`, `skills-2025-10-02`, `files-api-2025-04-14`. No network access in container.
- **Claude Code**: filesystem-based (`~/.claude/skills/` personal, `.claude/skills/` project). Full network access.

**Pre-built skills (as of this fetch):** pptx, xlsx, docx, pdf.

**Security note added in recent docs:** Skills from untrusted sources can exfiltrate data or misuse tools — audit before installing.
