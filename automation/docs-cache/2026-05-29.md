### Key sections (as of 2026-05-29)

#### Why use Skills
Skills are reusable, filesystem-based resources that provide Claude with domain-specific expertise. Unlike one-off prompts, Skills load on-demand and eliminate repeated guidance across conversations.

#### How Skills work — three-level loading
- **Level 1 (always loaded):** YAML frontmatter — `name` and `description` only. ~100 tokens per Skill. Loaded at startup into system prompt.
- **Level 2 (triggered):** SKILL.md body. Loaded via bash read when the skill matches a request. Under 5k tokens.
- **Level 3 (as needed):** Bundled files (FORMS.md, scripts, resources). Accessed on demand via bash. No context cost until accessed.

#### Frontmatter schema (required fields)
```yaml
---
name: your-skill-name        # max 64 chars, lowercase + hyphens, no "anthropic"/"claude"
description: >-              # non-empty, max 1024 chars, no XML tags
  What the skill does and when Claude should use it.
---
```

#### Skill structure
```
skill-name/
├── SKILL.md          # required — frontmatter + instructions
├── ADDITIONAL.md     # optional — supplementary instructions
└── scripts/
    └── utility.py    # optional — executable code
```

#### Surface availability
- **claude.ai**: Custom Skills uploaded as zip via Settings > Features. Individual per user (not org-wide). Pro/Max/Team/Enterprise with code execution enabled.
- **Claude API**: Custom Skills workspace-wide. Uploaded via `/v1/skills` endpoints.
- **Claude Code**: Filesystem-based at `~/.claude/skills/` or `.claude/skills/`. Not synced to cloud surfaces.

#### Runtime constraints (claude.ai)
Varying network access depending on user/admin settings. Skills may have full, partial, or no network access.

#### Pre-built Skills (API/claude.ai)
PowerPoint (`pptx`), Excel (`xlsx`), Word (`docx`), PDF (`pdf`) — all for document creation/editing.

#### Description best practice (from docs)
> The description should include both what the Skill does and **when Claude should use it**. Claude uses this at startup to decide whether to invoke the skill.

## Authoring notes (relevant to today's skill build)

1. `description` is the discovery signal. Must be third-person, keyword-rich, and include explicit trigger phrases — Claude under-fires on skill activation.
