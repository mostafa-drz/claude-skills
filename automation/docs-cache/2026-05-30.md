### Key sections

#### Skill structure (required)

Every Skill requires a `SKILL.md` with YAML frontmatter:

```yaml
---
name: your-skill-name          # max 64 chars, lowercase, hyphens, no XML tags
description: Brief description # non-empty, max 1024 chars, no XML tags
---
```

`description` should include both what the Skill does and when Claude should use it.

#### Three-level progressive loading

| Level | When Loaded | Token Cost | Content |
|-------|------------|------------|---------|
| Level 1: Metadata | Always (at startup) | ~100 tokens per Skill | `name` + `description` from frontmatter |
| Level 2: Instructions | When Skill is triggered | Under 5k tokens | SKILL.md body |
| Level 3+: Resources | As needed | Effectively unlimited | Bundled files via bash |

#### Where Skills work

- **claude.ai**: custom Skills uploaded as zip via Settings > Features. Individual to each user (not org-wide). Pro/Max/Team/Enterprise with code execution enabled.
- **Claude API**: workspace-wide. Requires beta headers `code-execution-2025-08-25`, `skills-2025-10-02`, `files-api-2025-04-14`.
- **Claude Code**: filesystem-based (`~/.claude/skills/` or `.claude/skills/`), personal or project-scoped.

#### Google Workspace integration (confirmed available in claude.ai Desktop)

Claude can connect Gmail, Google Calendar, and Google Drive as connectors. Calendar integration supports: read events, create events, update events, delete events, RSVP, check availability. Write operations are available in claude.ai with connector permissions.

#### Pre-built Skills (API/claude.ai)

PowerPoint (pptx), Excel (xlsx), Word (docx), PDF (pdf) — available without custom setup.

#### Security note

Only use Skills from trusted sources. Skills can invoke tools and run code — treat like installing software.
