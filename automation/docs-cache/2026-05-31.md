## platform.claude.com — Agent Skills Overview (key sections)

Source: https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview

### What Skills are

Skills are modular, filesystem-based capabilities that extend Claude. Each Skill packages
instructions, metadata, and optional resources (scripts, templates) that Claude loads
on-demand when relevant to a request.

Three levels of loading:
- **Level 1 (always):** YAML frontmatter (`name`, `description`) — ~100 tokens per skill, loaded at startup
- **Level 2 (on trigger):** SKILL.md body — under 5k tokens, loaded when skill activates
- **Level 3 (as needed):** Bundled files (scripts, reference docs) — Claude reads via bash, no context cost until accessed

### Frontmatter requirements

```yaml
---
name: skill-name          # ≤64 chars, lowercase, hyphens only, no XML tags
description: >-           # ≤1024 chars, non-empty, no XML tags
  What the skill does and when to use it.
---
```

Both `name` and `description` are required. The description should include what the Skill
does AND when Claude should use it (trigger keywords).

### Platform availability

- **claude.ai:** Custom Skills via Settings > Features (Pro/Max/Team/Enterprise, code exec required). Individual per user, not org-wide.
- **Claude Code:** Filesystem-based. Personal (`~/.claude/skills/`) or project (`.claude/skills/`).
- **Claude API:** Workspace-wide. Upload via `/v1/skills` endpoint.

### Runtime constraints (claude.ai)

- Varying network access depending on user/admin settings
- No local filesystem outside the sandbox VM

### Runtime constraints (Claude Code)

- Full network access
- Filesystem-based, no API upload needed
- Skills live in `~/.claude/skills/` or `.claude/skills/`

### New in 2026 (noted from overview)
