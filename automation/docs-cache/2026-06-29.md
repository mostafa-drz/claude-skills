### Key Sections (Source 3)

**What Skills are:**
Skills are reusable, filesystem-based resources that provide Claude with domain-specific expertise: workflows, context, and best practices. Unlike prompts (conversation-level, one-off), Skills load on-demand and eliminate repeated guidance across conversations.

**Three types of content, three loading levels:**
- Level 1 — Metadata (always loaded): YAML frontmatter `name` + `description`. ~100 tokens per skill. Loaded at startup.
- Level 2 — Instructions (triggered): SKILL.md body. Under 5k tokens. Loaded when skill activates.
- Level 3 — Resources (as needed): bundled scripts, reference files. Effectively unlimited. Never loaded into context unless referenced.

**Required frontmatter fields:**
```yaml
name: your-skill-name          # max 64 chars, lowercase + hyphens, no "anthropic"/"claude"
description: Brief description  # max 1024 chars, non-empty, no XML tags
```

**SKILL.md body structure (from platform docs):**
```markdown
# Skill Name

## Instructions
[step-by-step guidance]

## Examples
[concrete examples]
```

**Where skills work:**
- **claude.ai**: Custom Skills via zip upload (Settings > Features). Pro/Max/Team/Enterprise with code execution. Individual user only, not org-wide.
- **Claude API**: `skill_id` in `container` parameter. Requires beta headers: `code-execution-2025-08-25`, `skills-2025-10-02`, `files-api-2025-04-14`. Workspace-wide sharing.
- **Claude Code**: Filesystem-based. `~/.claude/skills/` (personal) or `.claude/skills/` (project). Full network access.

**Runtime constraints (Desktop/claude.ai):**
- Varying network access depending on user/admin settings.
- Skills provide filesystem-like access inside the VM. Claude navigates the skill dir like bash commands.

**Security note:** Only install Skills from trusted sources. Malicious Skills can invoke tools (file operations, bash, code execution) in harmful ways.

**Pre-built skills available (API/claude.ai):** PowerPoint (pptx), Excel (xlsx), Word (docx), PDF (pdf)

**Open-source examples:** https://github.com/anthropics/skills — includes `skill-creator` and others.
