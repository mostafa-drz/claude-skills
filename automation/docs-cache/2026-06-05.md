## Source 3 — Agent Skills Overview (Platform Docs)

**URL:** https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview
**Status:** 200 OK

### Key sections

#### What Skills are
- Reusable, filesystem-based resources that give Claude domain-specific expertise
- Load on-demand via progressive disclosure (metadata → instructions → resources)
- Unlike prompts: persist across conversations, eliminate repeated setup

#### Three levels of loading
- **Level 1 (Metadata)**: YAML frontmatter always loaded at startup (~100 tokens per skill)
- **Level 2 (Instructions)**: SKILL.md body loaded when triggered (under 5k tokens)
- **Level 3 (Resources)**: Bundled files (scripts, templates, reference docs) loaded as needed

#### SKILL.md required fields
```yaml
---
name: your-skill-name           # max 64 chars, lowercase/hyphens, no XML tags, no reserved words
description: Brief description  # non-empty, max 1024 chars, no XML tags
---
```
- Description must say both **what** the skill does and **when** to use it.

#### Where Skills work
- **claude.ai**: individual user, uploaded via Settings > Features as a zip
- **Claude API**: workspace-wide, via `/v1/skills` endpoints
- **Claude Code**: filesystem-based (`~/.claude/skills/` personal, `.claude/skills/` project), no upload needed

#### Runtime environment — claude.ai (Desktop context)
- **Varying network access** depending on user/admin settings
- No code execution container (unlike API)
- Google Workspace integrations available via MCP

#### Sharing scope
- claude.ai: individual user only
- Claude Code: personal or project-based (shareable via Plugins)

#### Security notes
- Audit all bundled files before use
- Skills from external sources can invoke tools in harmful ways
