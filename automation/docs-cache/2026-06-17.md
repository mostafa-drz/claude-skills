## platform.claude.com — Agent Skills Overview (retrieved 2026-06-17)

### Key authoring facts

**Required frontmatter**
```yaml
---
name: your-skill-name       # ≤64 chars, lowercase + hyphens; no "anthropic"/"claude"
description: >-             # non-empty, ≤1024 chars, third-person, trigger-rich
  Does X when the user asks for Y. Use when <trigger>.
---
```

**Progressive loading**
- Level 1 (always): name + description, ~100 tokens per skill
- Level 2 (on trigger): SKILL.md body, <5k tokens
- Level 3 (as needed): bundled files/scripts, no context cost until accessed

**Surface constraints — claude.ai (Desktop)**
- Varying network access (depends on user/admin settings)
- Code execution available on Pro/Max/Team/Enterprise
- Google Workspace (Calendar, Gmail, Drive) available via connected apps

**Custom Skills on claude.ai**
- Individual user only — not org-wide
- Uploaded as zip via Settings > Features
