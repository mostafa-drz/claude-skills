### Key sections extracted

#### Three levels of skill content

| Level | When Loaded | Token Cost | Content |
|-------|------------|------------|---------|
| Level 1: Metadata | Always (startup) | ~100 tokens per skill | `name` + `description` from YAML |
| Level 2: Instructions | When skill triggers | Under 5k tokens | SKILL.md body |
| Level 3+: Resources | As needed | Effectively unlimited | Bundled files, scripts |

#### Frontmatter requirements

```yaml
name: your-skill-name         # max 64 chars, lowercase letters/numbers/hyphens only
description: >-               # non-empty, max 1024 chars, no XML tags
  What the skill does and when to use it.
```

Reserved words that cannot appear in `name`: "anthropic", "claude".

#### Runtime environment by surface

- **claude.ai**: varying network access depending on user/admin settings
- **Claude API**: no network access, no runtime package installation
- **Claude Code**: full network access; avoid global package installation

#### Skill structure

```
skill-name/
├── SKILL.md          (required — frontmatter + instructions)
├── additional.md     (optional — loaded on demand by reference)
└── scripts/
    └── helper.py     (optional — executed via bash, output enters context)
```

#### Security note

Only use skills from trusted sources. Skills with bash/code execution can
exfiltrate data or access filesystems in unintended ways if malicious.
