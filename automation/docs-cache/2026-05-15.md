## §1 — platform.claude.com/docs/en/agents-and-tools/agent-skills/overview

**Retrieved**: 2026-05-15T07:00:00Z (approx)

### Key sections relevant to skill authoring

**Why Skills**
Skills are reusable, filesystem-based resources providing Claude with domain-specific expertise. Unlike conversation-level prompts, Skills load on-demand across sessions without re-prompting.

**Three-level loading model**
- Level 1 (Metadata): YAML frontmatter — always loaded at startup, ~100 tokens per skill.
- Level 2 (Instructions): SKILL.md body — loaded when the skill is triggered, under 5k tokens.
- Level 3 (Resources): Additional bundled files and scripts — loaded only as referenced.

**Frontmatter requirements**
```yaml
---
name: your-skill-name          # max 64 chars, lowercase letters/numbers/hyphens only
description: what it does      # non-empty, max 1024 chars, no XML tags
---
```
Reserved words that cannot appear in `name`: "anthropic", "claude".

**Where Skills work**
- **claude.ai**: Custom Skills via zip upload. Available on Pro/Max/Team/Enterprise with code execution enabled. Per-user only (not org-wide).
- **Claude Code**: Filesystem-based (`~/.claude/skills/` or `.claude/skills/`). No upload required. Full network access.
- **Claude API**: Skills uploaded via `/v1/skills` endpoints. Workspace-wide. No network access inside the container.

**Runtime constraints for claude.ai (Desktop)**
Varying network access depending on user/admin settings. Skills may have full, partial, or no network access. Google Workspace MCP and other configured MCP servers are available when connected.

**Security note (for awareness)**
Skills from untrusted sources can invoke tools in harmful ways. Routine-built skills are first-party; no third-party code is bundled.

**Pre-built Skills (reference — not used in custom skill authoring)**
PowerPoint (pptx), Excel (xlsx), Word (docx), PDF (pdf) — available on API and claude.ai.
