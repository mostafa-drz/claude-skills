## Source 3 — https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview

**Status: 200 OK** — full content retrieved.

### Required frontmatter fields

| Field | Constraint |
|---|---|
| `name` | Max 64 chars. Lowercase letters, numbers, hyphens only. No "anthropic" or "claude". |
| `description` | Non-empty. Max 1024 chars. Must state WHAT it does AND WHEN to use it. |

### Three levels of loading

| Level | When loaded | Token cost | Content |
|---|---|---|---|
| 1 — Metadata | Always (startup) | ~100 tokens per Skill | YAML frontmatter |
| 2 — Instructions | When triggered | Under 5 k tokens | SKILL.md body |
| 3 — Resources | As needed | Effectively unlimited | Bundled files / scripts |

### Runtime constraints for claude.ai (Desktop)

- Network access: varies by user/admin settings (full, partial, or none).
- Code execution must be enabled.
- Custom Skills are individual per user — not shared org-wide.

### Where Skills work

| Surface | Custom Skills | Notes |
|---|---|---|
| claude.ai | Yes (upload as ZIP) | Pro/Max/Team/Enterprise; code execution required |
| Claude API | Yes (via /v1/skills) | Workspace-wide sharing |
| Claude Code | Yes (filesystem) | Personal (`~/.claude/skills/`) or project (`.claude/skills/`) |

Custom Skills do **not** sync across surfaces.
