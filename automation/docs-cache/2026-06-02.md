## Key Sections (from platform docs)

### Skill structure

Every Skill requires a `SKILL.md` file with YAML frontmatter:

```yaml
---
name: your-skill-name          # lowercase, hyphens, ≤64 chars, no XML tags, no reserved words
description: >-                # non-empty, ≤1024 chars, no XML tags
  Brief description of what this Skill does and when to use it.
---
```

### Three-level loading model

- **Level 1 — Metadata** (always loaded, ~100 tokens): name + description from frontmatter
- **Level 2 — Instructions** (loaded when triggered, <5k tokens): SKILL.md body
- **Level 3 — Resources** (loaded as needed, no practical limit): bundled files, scripts

### Where Skills run

- **claude.ai**: code execution sandbox with varying network access (user/admin controlled)
- **Claude API**: code execution container, no network access, pre-installed packages only
- **Claude Code**: full network access, filesystem-based, no upload required

### Desktop Skills context (claude.ai)

Custom Skills uploaded as zip files via Settings > Features. Individual per user (not org-wide). Available on Pro, Max, Team, Enterprise with code execution enabled.
