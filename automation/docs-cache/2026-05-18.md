### Three-level loading model

| Level | When Loaded | Token Cost | Content |
|-------|-------------|------------|---------|
| Level 1: Metadata | Always (at startup) | ~100 tokens per Skill | `name` + `description` from YAML frontmatter |
| Level 2: Instructions | When Skill is triggered | Under 5k tokens | SKILL.md body |
| Level 3+: Resources | As needed | Effectively unlimited | Bundled files executed via bash |

### Required frontmatter

- `name`: max 64 chars, lowercase letters/numbers/hyphens only. Cannot contain XML tags or reserved words ("anthropic", "claude").
- `description`: non-empty, max 1024 chars, no XML tags. Should say what the skill does AND when to use it.

### Where Skills work

- **claude.ai**: custom Skills (Pro/Max/Team/Enterprise), individual user scope, upload via Settings > Features as zip; varying network access.
- **Claude API**: custom + pre-built Skills, workspace-wide scope; no network access, no runtime package installation.
- **Claude Code**: filesystem-based, full network access, personal (`~/.claude/skills/`) or project (`.claude/skills/`).

### Pre-built Skills

PowerPoint (pptx), Excel (xlsx), Word (docx), PDF (pdf)
