#### Progressive loading model (three levels)

| Level | When Loaded | Token Cost | Content |
|-------|-------------|------------|---------|
| Level 1: Metadata | Always (startup) | ~100 tokens per Skill | `name` + `description` from frontmatter |
| Level 2: Instructions | When Skill triggered | Under 5k tokens | SKILL.md body |
| Level 3+: Resources | As needed | Effectively unlimited | Bundled files read via bash |

**Implication for authoring**: description must be trigger-rich (used at startup for matching); body can be detailed (only loaded when matched).

#### Platform availability

| Surface | Custom Skills | Pre-built Skills |

| claude.ai | ✅ (individual user only) | ✅ |
| Claude API | ✅ (workspace-wide) | ✅ |

#### Runtime constraints by surface

- **claude.ai**: varying network access depending on user/admin settings
- **Claude API**: no network access, no runtime package install
- **Claude Code**: full network access, global package install discouraged

#### Security note

Skills provide Claude with capabilities through instructions and code. Only use Skills from trusted sources. Malicious Skills can invoke tools in harmful ways.
