```yaml
---
name: your-skill-name    # max 64 chars; lowercase + hyphens; no XML tags; no reserved words

---
```

#### Three loading levels
| Level | When loaded | Token cost | Content |
|-------|-------------|------------|---------|
| 1: Metadata | Always, at startup | ~100 tokens/skill | `name` + `description` from frontmatter |
| 2: Instructions | When skill is triggered | < 5k tokens | SKILL.md body |
| 3+: Resources | As needed | Effectively unlimited | Bundled files (scripts, markdown, data) accessed via bash |

**Implication for authoring:** Description is always in context. Keep it tight and trigger-rich. SKILL.md body only loads on demand — can be more verbose.
