### Key sections

**Three-level progressive loading**:
- Level 1 (Metadata): YAML frontmatter, always loaded at startup (~100 tokens/skill)
- Level 2 (Instructions): SKILL.md body, loaded when triggered (<5k tokens)
- Level 3+ (Resources): Bundled files (scripts, reference docs), loaded on demand, no token cost until accessed

**Required frontmatter fields**:
```yaml
---
name: skill-name          # ≤64 chars, lowercase, hyphens, no reserved words
description: >-           # non-empty, ≤1024 chars, no XML tags
  What it does and when to use it.
---
```

**Where Skills work**:
- `claude.ai`: supports custom Skills (zip upload), individual user scope
- Claude API: custom + pre-built, workspace-wide scope
- Claude Code: filesystem-based at `~/.claude/skills/` or `.claude/skills/`

**Runtime environment for claude.ai Desktop**:
- Varying network access depending on user/admin settings
- Google Workspace connectors (Gmail, Calendar, Drive) available when connected
- Sandboxed code execution available

**Pre-built skills** (PowerPoint, Excel, Word, PDF): not relevant for custom Desktop skills.

**Security note**: Only use Skills from trusted sources. Skill instructions and bundled scripts have filesystem and tool access.
