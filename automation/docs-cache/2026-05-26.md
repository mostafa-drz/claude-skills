## Key sections — platform.claude.com/docs (agent-skills/overview)

### Skill structure (required)

Every Skill requires a `SKILL.md` file with YAML frontmatter:

```yaml
---
name: your-skill-name          # max 64 chars, lowercase + hyphens only, no "anthropic" / "claude"
description: >-                # non-empty, max 1024 chars, no XML tags
  What this Skill does and when to use it.
---
```

**Required fields**: `name` and `description` only.

### Three levels of loading

| Level | When | Token cost | Content |
|-------|------|------------|---------|
| Metadata | Always (startup) | ~100 tokens/Skill | `name` + `description` from frontmatter |
| Instructions | When triggered | < 5 k tokens | SKILL.md body |
| Resources | As needed | Effectively unlimited | Bundled files (scripts, reference, templates) |

### Desktop / claude.ai-specific constraints

- **Varying network access**: depending on user/admin settings, Skills may have full, partial, or no network access.
- Custom Skills on claude.ai are **individual to each user**; not org-wide.
- Skills uploaded to claude.ai must be separately uploaded to the API — they do not sync.
- Upload format: zip file via Settings > Features (Pro, Max, Team, Enterprise with code execution enabled).

### Description best practice (recovered from web search — Tier 3 practitioner sources)

- Description is the trigger mechanism. Claude reads it at startup to decide whether to load the skill.
- Bad description → skill never fires regardless of instruction quality.
- Include: what the skill does + concrete trigger phrases a user would say.
- Broad trigger keywords outperform narrow ones; Claude under-fires on skill activation.

### Frontmatter optional fields (Claude Code context; partially applicable to Desktop)

```yaml
disable-model-invocation: true   # user-invocable only; Claude won't auto-invoke
user-invocable: false            # hidden from menu; Claude-only invocation
context: fork                    # isolated subagent execution (Claude Code only)
allowed-tools:                   # restrict which tools the skill may use (Claude Code only)
  - Bash(git *)
```
